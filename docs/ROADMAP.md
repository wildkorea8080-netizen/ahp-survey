# 단계별 로드맵

## 1단계 (현재) — 내부 운영
- 단일 설문(해농공매 AHP) 운영
- 관리자 단독 인증
- 응답자 설문 수집
- 4개/3개 항목 독립 분석
- CR 보정 기능
- 개별 확인서 + 보고서 PDF
- 한국어 단일 언어

## 2단계 확장 포인트 (코드 구조 준비)
- src/services/ 레이어 분리 → 결제 서비스 추가 용이
- User 모델 스텁 → 회원가입 추가 용이
- ownerId 필드 → 멀티 사용자 대시보드 용이
- 기능 플래그(FEATURE_AUTH, FEATURE_PAYMENT) → 단계별 활성화
- Stripe 결제 모듈 구조 준비 (실제 구현은 2단계)

## 3단계 확장 포인트
- locales/ 디렉터리 구조 → next-i18next 즉시 연결 가능
- t('key') 방식 UI 텍스트 → 번역 파일만 추가하면 동작
- PDF 문구 리소스 분리 → 다국어 PDF 생성 용이
- 이메일 템플릿 리소스 분리
- 우선 지원: ko(한국어), en(영어)
- 추가 예정: ja(일본어), zh(중국어)
