## rawValue 규칙
rawValue > 0 → 좌측(A) rawValue배 중요 → matrix[A][B] = rawValue
rawValue < 0 → 우측(B) |rawValue|배 중요 → matrix[A][B] = 1/|rawValue|
rawValue = 0 → 동등 → matrix[A][B] = 1

## 계산 순서
1. 4×4 행렬 생성 (대각=1, 하삼각=역수)
2. 열 합 계산 → 정규화
3. 행 평균 = 가중치
4. λmax = Σ(Aw_i / w_i) / n
5. CI = (λmax - n) / (n - 1)
6. CR = CI / RI[n]

## RI 테이블

## 판정
