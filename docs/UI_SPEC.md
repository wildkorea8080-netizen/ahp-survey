## CR 배지
CR ≤ 0.1  → 초록 "✅ 허용"
CR > 0.1  → 빨간 "⚠ 재설문"
보정 후   → 노란 "🔧 보정됨"

## i18n 주의사항 (3단계 대비)
- 하드코딩 텍스트 금지
- 모든 UI 텍스트는 t('key') 형식으로 작성
- 현재는 ko 로케일 기본값 사용
